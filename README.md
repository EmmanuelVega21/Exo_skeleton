# Exo_skeleton

## Arduino setup

This sketch depends on the `Adafruit PWM Servo Driver` library.

Install it from the Arduino Library Manager, or use the GitHub repository:

```text
https://github.com/adafruit/Adafruit-PWM-Servo-Driver-Library
```

If you are using `arduino-cli`, install it with:

```bash
arduino-cli lib install "Adafruit PWM Servo Driver"
```
